# Hisab APK (Capacitor + GitHub Actions)

1. Put your real `fb-init.js` **and `IMG_20251116_215737_558.webp`** (profile photo) in `www/`.
2. Push everything to a GitHub repo (branch `main`).
3. Repo -> Actions -> "Build APK" -> open the latest run -> download **Hisab-apk** at the bottom.
4. Unzip, install `app-debug.apk` on your phone.

Firebase Realtime Database rules are in `database_rules.json` (paste into Firebase console -> Realtime Database -> Rules).
